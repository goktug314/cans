# Cans — Lezzetli seçimler, iyi hisler

Yiyecek, içecek ve atıştırmalık mağazası için GitHub Pages uyumlu, tek sayfalık statik site taslağıdır. Ürün arama, kategori seçimi, sıralama ve tarayıcıda saklanan sepet bulunur.

## GitHub Pages ile yayınlama

1. `index.html`, `.nojekyll` ve `README.md` dosyalarını GitHub deposunun en üst düzeyine yükle.
2. Depoda **Settings → Pages** bölümünü aç.
3. **Deploy from a branch** seç; dalı `main`, klasörü `/ (root)` yapıp kaydet.
4. GitHub Pages adresi `https://KULLANICI-ADIN.github.io/DEPO-ADI/` biçiminde olur.

Ürün adları ve fiyatlar örnektir. Ödeme ve sipariş gönderme altyapısı bu taslağa bağlı değildir; teslimat formu yalnızca önizleme içindir.
